# Project plan

## Current scope
CSV validation, transparent heuristic scoring, and report export.

## Next priorities
1. Improve provenance: add evidence collection date and confidence fields.
2. Allow scoring weights to be configured from a validated file.
3. Add currency and locale handling.
4. Build a small browser interface only after CLI behavior is stable.
5. Evaluate scores against real outcomes using opt-in, anonymized data.

## Definition of done
- Clear problem statement and documentation.
- Automated tests for core behavior.
- No secrets or private data.
- Honest limitations and reproducible examples.
- Release notes for user-visible changes.

## Maintainer notes
Do not claim users, downloads, marketplace integrations, or validated accuracy unless you can demonstrate them. Record real issues, decisions, and changes as the project evolves.
