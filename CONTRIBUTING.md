# Contributing

Thanks for considering a contribution.

1. Open an issue describing the problem or proposed change.
2. Keep changes focused and explain the reasoning.
3. Add or update tests for behavior changes.
4. Run `pytest` before submitting a pull request.
5. Never commit API keys, credentials, personal data, or private business data.
6. For scoring changes, explain assumptions and avoid presenting the score as a sales prediction.

Be respectful and constructive. By contributing, you agree that your contribution may be distributed under the MIT License.
